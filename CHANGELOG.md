# Changelog

## 1.0.1

- The preview now scales down to fit the screen, so the whole image is always visible without scrolling. Exports are still full size.

## 1.0.0

First public release.

- All 19 color themes bundled with Xcode, plus import of your own `.xccolortheme` files.
- Xcode-style coloring: declared types and functions get project colors, everything else system colors.
- Native PNG export at 1× to 4× and vector SVG with embedded fonts.
- Xcode, plain macOS or no window chrome, with editable file and project names.
- Frame shapes (Auto, 16:9, 4:3, 1:1), nine backgrounds and an adjustable window width.
- SF Mono plus bundled JetBrains Mono, Geist Mono, IBM Plex Mono and Fira Code.
- Language detection on paste, line highlighting, share links.
- Works offline and installs as an app; Docker image for amd64 and arm64; umbrelOS community app store.
